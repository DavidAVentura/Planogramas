# Publicar Demo En jcddash.com/surtido

## Build

```bash
npm run build
```

## Subida

Subir el contenido de `dist/` dentro de la carpeta pública del servidor:

```text
jcddash.com/surtido/
```

Debe quedar así:

```text
surtido/index.html
surtido/assets/...
```

## Datos De La Demo

- Productos: muestra real desde `Autos.xlsx`.
- Muebles: consolidado de accesorios/merchandising.
- Performance: datos simulados para demo.
- Flujo futuro sugerido: BI/POS + VTEX + catálogo procesado por n8n hacia un JSON/API consumido por esta app.
